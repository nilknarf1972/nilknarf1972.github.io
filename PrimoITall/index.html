🌐 Network Testing Toolkit 10 Essential Tools

Instant 1-click execution for network troubleshooting, latency probing, sockets, DNS, and stack resets.

Windows Diagnostics
⚡ Flush DNS Cache DNS
ipconfig /flushdns

Clears local DNS resolver cache to purge stale entries and fix unreachable hostnames.

📋 IP Configuration CONFIG
ipconfig /all

Detailed network adapter telemetry, MAC addresses, DHCP lease times, and DNS servers.

📶 Ping Latency Test PING
ping -n 4 [target]

Sends ICMP echo requests to measure roundtrip latency (ms) and packet drop rate.

🗺️ Trace Route (Hops) ROUTE
tracert -d -h 15 [target]

Traces every router hop along the path to diagnose network bottlenecks and gateway routing.

🔌 Active Ports & Sockets SOCKETS
netstat -ano

Lists listening TCP/UDP ports, established remote connections, and associated Process IDs.

🔎 DNS Name Lookup DNS
nslookup [target]

Queries active nameservers to resolve hostnames to IP addresses or verify DNS records.

🖧 ARP Subnet Map ARP
arp -a

Displays Address Resolution Protocol cache mapping subnet IPs to physical hardware MAC addresses.

🛡️ Reset Winsock & IP ADMIN
netsh winsock reset

Repairs corrupted Windows network catalogs and resets TCP/IP stack to factory defaults.

🔄 DHCP Release & Renew DHCP
ipconfig /release && /renew

Releases stale DHCP lease and negotiates a brand-new IP address configuration from router.

📡 Wi-Fi Signal & Info WI-FI
netsh wlan show interfaces

Queries active Wi-Fi radio type, connected SSID, BSSID, channel, and signal strength %.
